If the [AI Assistant plugin](../integrations/add_ai_assistant.mdx) is enabled, you'll be able to use below AI features powered by LLM.

## Title Generation

Click the '#' icon will generate title of the query cell automatically.
![](/img/user_guide/title_generation.gif)

## Text To SQL

Type a question in the AI box above a query cell and press Enter. Type `@` to pick tables, or `/` to choose a command.

### Query Generation

If the query cell is empty, the AI writes a new query. Select the table(s) to query and type your question. If you're unsure which tables to use, type the question anyway and the AI will try to find tables for you.

![](/img/user_guide/text_to_sql.gif)

### Query Editing

If the query cell already has a query, the AI edits that query to answer your question.

![](/img/user_guide/text_to_sql_edit.gif)

### Reviewing the result

The request runs in the background, so you can keep working. When it's done, a notification appears. Click **View** in the notification, or on the AI box, to open the result.

The result shows the AI's explanation and the difference between your query and the AI's query. If the AI needs you to choose tables first, pick them and click **Continue**.

-   **Accept** replaces your query with the AI's query.
-   **Reject** throws the AI's query away.
-   **Dismiss**, clicking outside the dialog, or pressing Escape closes the dialog and keeps the result. Click **View** to open it again.

### Requesting changes

To refine the AI's query, describe what to change in **Request changes** and press Enter or click **Submit**. Use Shift+Enter for a new line. The AI revises its query in the background, and you can view the new version when it's ready. If the revision fails, the previous version is kept.

## SQL Fix

If your query failed, you will see ‘Auto fix’ button on the right corner of the error message

![](/img/user_guide/sql_fix.gif)

## SQL Completion

SQL completion offers SQL code suggestions similar to GitHub Copilot while you write queries.
This feature is disabled by default. You can enable it in the Editor tab of user settings.

![](/img/user_guide/sql_complete.png)

## Search Tables and Queries by Natural Language

If the [vector store](../integrations/add_ai_assistant.mdx#vector-store) of the AI assistant plugin is enabled, you'll be able to search both tables and queries using natural language in addition to traditional keyword-based search.

![](/img/user_guide/table_vector_search.png)
